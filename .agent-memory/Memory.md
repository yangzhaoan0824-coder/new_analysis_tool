                      会话摘要 + 巩固机制
 ═══════════════════════════════════════════════════════════════════
 
   ┌─────────────────────────────────────────────────────────┐
   │              会话摘要（Auto Session Summary）             │
   │                                                         │
   │  触发：8-10轮 / AWS变更后 / 用户说"保存"                  │
   │  输出：session_summaries/summary_YYYY-MM-DD.md          │
   │  作用：详细历史记录存档                                   │
   └───────────────────────────┬─────────────────────────────┘
                               │
                               ▼
   ┌─────────────────────────────────────────────────────────┐
   │           记忆巩固 / 做梦（Memory Consolidation）         │
   │                                                         │
   │  触发：距上次 ≥3天 或 未归档摘要 ≥3份                     │
   │  流程：                                                  │
   │    ① 一致性校验（索引 vs 实际文件）                       │
   │    ② 收集新摘要，检查遗漏                                │
   │    ③ 合并（矛盾以最新为准）                              │
   │    ④ 分层迁移（Hot→Warm→Cold）+ 文件大小检查             │
   │    ⑤ 探索（搜索相关更新，写入 discoveries.md）           │
   │  输出：🌙 做梦报告                                       │
   └─────────────────────────────────────────────────────────┘
